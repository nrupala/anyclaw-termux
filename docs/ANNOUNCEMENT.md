# Announcement draft (post when stack is stable)

Title: AnyClaw-Termux — native Termux rebuild of the AnyClaw stack

We rebuilt the AnyClaw concept as a native Termux stack: OpenClaw + Codex CLI +
opencode + local Vulkan llama.cpp on Android — no embedded APK runtime, durable
against app reinstalls, GPU-accelerated, fully ours.

Huge thanks and credit to the original builders:
@OpenClawAndroid, @openclaw, @openai, @sst, @ggml-org, @termux

MIT + Apache-2.0 with a commercial-use rider. Feedback and collaboration welcome.
